สารบัญหมวดหมู่

เนื้อหาอ้างอิงตามมาตรฐานสถาปัตยกรรมคอมพิวเตอร์และการสนับสนุนเทคโนโลยีไอที (IT Support)

ศูนย์รวมทฤษฎี & คู่มือปฏิบัติงานไอที

คู่มือศึกษาการบริหารจัดการระบบและแก้ปัญหาคอมพิวเตอร์

รวบรวมองค์ความรู้ทฤษฎีทางเทคนิค โครงสร้างฮาร์ดแวร์-ซอฟต์แวร์ ตารางเปรียบเทียบคำสั่ง และแนวทางการวิเคราะห์อาการเสียเชิงวิศวกรรมไอทีโดยไม่มีข้อสอบเจือปน

กำลังกรองเนื้อหาตามคำค้น:
1

ระบบปฏิบัติการและสถาปัตยกรรม (Operating Systems & Kernel)

โครงสร้างแกนกลาง การสื่อสารกับฮาร์ดแวร์ และกระบวนการ บูตเครื่อง (Boot Sequence)

1.1 หน้าที่หลักของระบบปฏิบัติการ และ Kernel

ระบบปฏิบัติการ (Operating System - OS) ทำหน้าที่เป็นตัวกลางในการบริหารจัดการทรัพยากรฮาร์ดแวร์ (CPU, Memory, Disk, I/O Devices) และอำนวยความสะดวกให้ซอฟต์แวร์ประยุกต์ (Applications) ทำงานได้อย่างมีประสิทธิภาพ

Kernel (แกนกลาง)

ส่วนประกอบลึกสุดที่เข้าถึงฮาร์ดแวร์โดยตรง ทำหน้าที่จัดสรรเวลา CPU (Process Scheduling), จัดการพื้นที่ RAM และควบคุม Driver

Shell (ส่วนปฏิสัมพันธ์)

ตัวประสานงานรับคำสั่งจากผู้ใช้เพื่อส่งต่อให้ Kernel ประมวลผล เช่น CLI (Command Line) หรือ GUI (Graphical User Interface)

Drivers (ส่วนควบคุม)

ซอฟต์แวร์เฉพาะทางที่แปลคำสั่งจาก OS ให้เป็นภาษาคำสั่งเฉพาะของฮาร์ดแวร์แต่ละประเภท

ประเภท OS ลักษณะลิขสิทธิ์ จุดเด่น & กลุ่มใช้งานหลัก
Windows (10/11) Proprietary ใช้งานทั่วไปในองค์กร ซัพพอร์ตซอฟต์แวร์และเกมหลากหลาย ไดรฟ์เวอร์สมบูรณ์
Ubuntu / Linux Open Source ซอร์สโค้ดเปิดเสรี เสถียรภาพสูง นิยมใช้ทำ Server, Cloud, Container และงานพัฒนาซอฟต์แวร์
macOS / iOS Proprietary ออกแบบเฉพาะอุปกรณ์ Apple มีความปลอดภัยสูง ระบบ Ecosystem ทำงานสอดประสานกันดีเยี่ยม

1.2 เฟิร์มแวร์ และกระบวนการบูตเครื่อง (Firmware & Boot Sequence)

Legacy BIOS + MBR

เฟิร์มแวร์รุ่นเก่า ทำงานแบบ 16-bit รองรับดิสก์พาร์ทิชันแบบ MBR (Master Boot Record) ซึ่งจำกัดขนาดดิสก์ไว้ไม่เกิน 2TB และแบ่ง Primary Partition ได้สูงสุด 4 พาร์ทิชัน

UEFI + GPT (มาตรฐานปัจจุบัน)

เฟิร์มแวร์ทันสมัย รองรับดิสก์ GPT (GUID Partition Table) ที่ความจุเกิน 2TB ได้ ทำงานเร็ว มีความปลอดภัยสูงด้วยระบบ Secure Boot ป้องกันการแอบโหลด Rootkit/Malware ขณะเปิดเครื่อง

ลำดับกระบวนการเปิดเครื่อง (Booting Steps):
  1. Power On Supply: จ่ายไฟเข้า เมนบอร์ดและ CPU เริ่มทำงาน
  2. POST (Power-On Self-Test): BIOS/UEFI ตรวจสอบฮาร์ดแวร์พื้นฐาน (RAM, GPU, Keyboard, Storage) หากพบปัญหาจะส่งเสียง Beep Code
  3. Boot Device Selection: BIOS/UEFI ค้นหาอุปกรณ์บูตตามลำดับ Boot Order ที่ตั้งไว้ (เช่น NVMe SSD, USB Flash Drive, Network)
  4. OS Bootloader Loading: อ่านโค้ด Bootloader (เช่น Windows Boot Manager หรือ GRUB) เข้าสู่หน่วยความจำเพื่อเริ่มโหลด Kernel ของ OS
2

ระบบไฟล์และการจัดเก็บข้อมูล (Storage & File Systems)

การจัดพาร์ทิชัน โครงสร้างระบบไฟล์ ความปลอดภัย และกลยุทธ์การสำรองข้อมูล

2.1 ตารางเปรียบเทียบระบบไฟล์ (File Systems)

NTFS (New Technology File System) Windows OS Main

ระบบไฟล์หลักของ Windows รองรับสิทธิ์เข้าถึง (NTFS Permissions), การบีบอัดไฟล์, File Encryption และระบบ Journaling ป้องกันไฟล์เสียเมื่อไฟดับ

FAT32 / exFAT Cross-Platform

FAT32 ใช้กับ Flash Drive ทั่วไป (จำกัดไฟล์เดี่ยวไม่เกิน 4GB), exFAT ปลดล็อกขีดจำกัดไฟล์ ใช้สำรองข้อมูลข้ามระบบปฏิบัติการ (Windows/macOS)

EXT4 / APFS Linux / macOS

EXT4 เป็นมาตรฐานของ Linux สถิติด้านความเร็วและ Journaling สูง / APFS ออกแบบมาสำหรับ SSD บน macOS โดยเฉพาะ

2.2 ความปลอดภัยและการบำรุงรักษาสื่อจัดเก็บข้อมูล

  • BitLocker Drive Encryption ฟีเจอร์เข้ารหัสดิสก์ระดับฮาร์ดแวร์/ซอฟต์แวร์บน Windows ป้องกันไม่ให้แฮกเกอร์ควัก SSD ออกไปต่อเครื่องอื่นเพื่อขโมยข้อมูลเมื่อโน้ตบุ๊กสูญหาย
  • S.M.A.R.T. Monitoring ระบบแจ้งเตือนสุขภาพไดรฟ์ (Self-Monitoring, Analysis and Reporting Technology) หากตรวจพบ SMART Warning ต้องรีบสำรองข้อมูลทันทีเพราะดิสก์ใกล้พัง
  • หลักการสำรองข้อมูล 3-2-1 Rule มีข้อมูลอย่างน้อย 3 สำเนา, เก็บในสื่อต่างชนิดกัน 2 ประเภท (เช่น SSD External + NAS), และมี 1 สำเนา เก็บไว้นอกสถานที่ (Off-site / Cloud Backup)
3

คำสั่ง CLI และเครื่องมือ Windows (CLI & Utilities)

สรุปคู่คำสั่ง Command Prompt, PowerShell และเครื่องมือช่างสำหรับวิเคราะห์ระบบ

3.1 สรุปชุดคำสั่ง CLI (Command Line Reference)

คำสั่ง (Command) วัตถุประสงค์และการใช้งาน ตัวอย่างการใช้งาน / สวิตช์
ipconfig ตรวจสอบการตั้งค่า IP Address, Subnet Mask และ Gateway ipconfig /all
(ดูรายละเอียด MAC & DHCP)
sfc System File Checker - ตรวจสอบและซ่อมแซมไฟล์ระบบ Windows ที่เสียหายโดยอัตโนมัติ sfc /scannow
chkdsk Check Disk - ตรวจสอบโครงสร้างระบบไฟล์และ Bad Sector บนฮาร์ดดิสก์ chkdsk c: /f /r
ping ส่งแพ็กเกจ ICMP ทดสอบการติดต่อกับอุปกรณ์เป้าหมายในเครือข่าย ping 127.0.0.1 (Loopback)
ping 192.168.1.1 (Gateway)
Task Manager

ตรวจสอบภาระงาน CPU, RAM, Disk (กรณี 100% Usage) รวมถึงบริหารจัดการ Startup Apps เพื่อลดระยะเวลาเปิดเครื่อง

Device Manager

ศูนย์จัดการ Driver ฮาร์ดแวร์ ตรวจจับเครื่องหมายตกใจสีเหลือง (Driver ปัญหา) และสั่งทำ Roll Back Driver ย้อนเวอร์ชัน

Event Viewer

ระบบบันทึก Log เหตุการณ์ย้อนหลัง (System, Application, Security) เพื่อวิเคราะห์หาสาเหตุอาการ Blue Screen หรือเครื่องดับสุ่ม

4

ระบบเครือข่ายและการตั้งค่า IP (Networking & IP Configuration)

การวิเคราะห์พารามิเตอร์เครือข่าย DHCP, DNS และการวิเคราะห์ปัญหาการเชื่อมต่อ

4.1 พารามิเตอร์พื้นฐานของ IPv4

  • IP Address: หมายเลขประจำเครื่องในระบบเครือข่าย (เช่น 192.168.1.50)
  • Subnet Mask: ตัวแบ่งแยกส่วน Network ID และ Host ID (เช่น 255.255.255.0)
  • Default Gateway: IP ของ Router ทำหน้าที่เป็นประตูทางออกสู่อินเทอร์เน็ตภายนอกองค์กร
  • DNS Server: ระบบแปลงชื่อเว็บไซต์ (Domain Name เช่น google.com) เป็น IP Address

4.2 อาการและจุดวิเคราะห์ปัญหา Network ที่พบบ่อย

ได้ IP 169.254.x.x (APIPA)

แสดงว่าเครื่องติดต่อแจก IP จาก DHCP Server ไม่ได้ (สายแลนหลวม, Wifi หลุด หรือ DHCP Server ล่ม)

Ping IP ได้ แต่เปิดเว็บด้วยชื่อโดเมนไม่ได้

ปัญหาเกิดจาก DNS Server มีปัญหา/ตั้งค่าผิด (เนื่องจากสื่อสารด้วย IP ตัวเลขได้ปกติ แต่แปลงชื่อเป็น IP ไม่สำเร็จ)

เข้าเว็บภายในได้ แต่เข้าเว็บภายนอกไม่ได้

ปัญหาเกิดจาก Default Gateway หรือเส้นทางเชื่อมต่อ Internet ออกนอกองค์กร มีอุปสรรค

5

ฮาร์ดแวร์ การบำรุงรักษา และความปลอดภัย (Hardware & Safety)

ไฟฟ้าสถิต (ESD) ระบบระบายความร้อน การวิเคราะห์สัญญาณเตือน Beep Code และ RAM

ESD & Safety Standards

ESD (Electrostatic Discharge) คือการคายประจุไฟฟ้าสถิตจากร่างกายมนุษย์สู่อุปกรณ์อิเล็กทรอนิกส์ ซึ่งทำความเสียหายชิปเซ็ตได้

ข้อปฏิบัติ: ดับไฟ ถอดปลั๊ก สวมสายรัดข้อมือกันไฟฟ้าสถิต (Anti-static Wrist Strap) ก่อนแตะต้องอุปกรณ์ภายใน

Thermal Management

เมื่อประมวลผลหนัก อุณหภูมิ CPU จะสูงขึ้น หากชุดระบายความร้อนหรือซิลิโคนเสื่อม ระบบจะสั่ง **Thermal Throttling** หรือดับเครื่องอัตโนมัติเพื่อป้องกัน CPU ไหม้

การบำรุงรักษา: ทำความสะอาดฝุ่นพัดลม ทา Thermal Paste ใหม่เป็นระยะ

UPS & POST Diagnostics

UPS (Uninterruptible Power Supply): สำรองไฟชั่วคราวและปรับแรงดันไฟให้คงที่ ป้องกันความเสียหายจากไฟดับกะทันหัน

Beep Code: รหัสเสียงแจ้งเตือนจาก BIOS เมื่อเกิดข้อผิดพลาดระดับฮาร์ดแวร์ก่อนแสดงภาพขึ้นจอ (เช่น RAM หรือ GPU หลวม/เสีย)

6

กระบวนการแก้ไขปัญหาเชิงระบบ (Systematic Troubleshooting Process)

แนวปฏิบัติมาตรฐาน 6 ขั้นตอนของ CompTIA A+ สำหรับช่างเทคนิคไอทีมืออาชีพ

กระบวนการแก้ปัญหา 6 ขั้นตอนมาตรฐาน (CompTIA A+ Standard)

ขั้นที่ 1: เก็บข้อมูลอาการ (Identify the Problem)

สอบถามอาการจากผู้ใช้ สังเกตสิ่งผิดปกติ ตรวจสอบ Log และทำ **Backup ข้อมูลสำคัญ** ของผู้ใช้ก่อนแตะต้องระบบเสมอ

ขั้นที่ 2: ตั้งสมมติฐานสาเหตุ (Establish Theory)

วิเคราะห์หาสาเหตุที่เป็นไปได้มากที่สุด โดยเริ่มจากสิ่งที่พื้นฐานที่สุดก่อน (เช่น ปลั๊กไฟ, สายเชื่อมต่อ, สวิตช์)

ขั้นที่ 3: ทดสอบสมมติฐาน (Test the Theory)

ทดสอบข้อสมมติฐานทีละประเด็น หากทดสอบแล้วไม่ตรง ให้ตั้งสมมติฐานใหม่เพื่อจำกัดขอบเขตปัญหา

ขั้นที่ 4: วางแผนและดำเนินการแก้ไข (Plan & Implement)

สร้างแผนการแก้ไขโดยคำนึงถึงผลกระทบข้างเคียงและปฏิบัติตามแผนเพื่อขจัดปัญหานั้น

ขั้นที่ 5: ยืนยันผลการแก้ไข (Verify System Functionality)

ทดสอบการทำงานของระบบแบบเต็มรูปแบบ เพื่อให้แน่ใจว่าปัญหาหายขาดและไม่เกิดอาการข้างเคียง พร้อมวางแนวทางป้องกัน

ขั้นที่ 6: บันทึกข้อมูล (Document Findings)

บันทึกอาการ สาเหตุ และขั้นตอนการแก้ปัญหาลงในระบบ Ticket / Knowledge base เพื่อใช้อ้างอิงในอนาคต

ผังการวิเคราะห์อาการเสียยอดฮิต (Quick Diagnostic Matrix)

เครื่องเปิดไม่ติด ไฟไม่เข้า
  1. เช็คเต้ารับ ปลั๊กไฟ และสายไฟ PSU
  2. ทดสอบ Power Supply Unit (PSU)
  3. ตรวจสอบสาย Front Panel บนเมนบอร์ด
พัดลมหมุน จอดำ Beep Code ดัง
  1. ถอด RAM มาทำความสะอาดหน้าสัมผัส
  2. เช็คการ์ดจอ (GPU) ว่าเสียบแน่นหรือไม่
  3. ฟังจำนวนเสียงสั้น/ยาว แปลความหมายตามคู่มือเมนบอร์ด
เครื่องช้า Disk 100%
  1. เช็ค Process ใน Task Manager
  2. ตรวจสุขภาพฮาร์ดดิสก์ด้วย SMART
  3. พิจารณาอัปเกรด HDD เป็น NVMe/SATA SSD
