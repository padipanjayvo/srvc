สรุปความรู้พื้นฐาน HTML, CSS & JavaScript

ยินดีต้อนรับสู่ศูนย์การเรียนรู้เชิงปฏิสัมพันธ์ เอกสารฉบับนี้รวบรวมองค์ประกอบสำคัญ 3 เสาหลักของการพัฒนาเว็บไซต์ ตั้งแต่การสร้างโครงสร้างหน้าเว็บ (HTML) การปรับแต่งความสวยงามเลย์เอาต์ (CSS) จนถึงการเขียนฟังก์ชันตอบโต้ผู้ใช้ (JavaScript)

1. โครงสร้างเว็บ (HTML)

ภาษาที่กำหนดโครงสร้างหลักของหน้าเว็บเพจ มีแท็กสำคัญอย่าง <html>, Semantic HTML และแอตทริบิวต์อย่าง src / alt

HyperText Markup Language

2. รูปแบบ & การจัดวาง (CSS)

ใช้ตกแต่งองค์ประกอบบนเว็บ ครอบคลุมเรื่อง CSS Box Model (Content, Padding, Border, Margin), Flexbox และ Media Queries สำหรับทำ Responsive Design

Cascading Style Sheets

3. การทำงาน & การตอบโต้ (JavaScript)

ภาษาโปรแกรมสำหรับสั่งการ ทำงานกับ DOM, การจัดการเหตุการณ์ (Events), การควบคุมตัวแปร (let / const) และ Strict Equality (===)

JavaScript (ES6+)

เครื่องมือจำลองแนวคิด (Interactive Visualizer Labs)

ทดลองปรับค่าแบบเรียลไทม์เพื่อทำความเข้าใจหลักการสำคัญจากเนื้อหา

Lab 2: JS Strict Equality (===) vs Loose (==)

เปรียบเทียบค่าและชนิดข้อมูล
Loose Equality (==)
true
แปลงชนิดข้อมูลก่อนเทียบ
Strict Equality (===)
false
เช็คทั้ง "ค่า" และ "ชนิดข้อมูล"
การเปรียบเทียบใน JS: === ปลอดภัยกว่าเพราะป้องกันการแปลงชนิดข้อมูลโดยไม่ตั้งใจ (Type Coercion)

แบบทดสอบทบทวน (Short Answer Quiz)
